# Murugan Goldsmith and Jewels — Final Frontend

A React/Vite jewellery shop website and shop-management frontend for Murugan Goldsmith and Jewels, Kuruvikulam.

## Included
- Home, Catalog, Product Details, Cart
- Custom Order request
- Customer Order tracking
- Admin dashboard
- Orders due today and delayed orders
- Customer order create/edit
- Goldsmith management (Ravi, Kumar, Mani, Suresh, Muthu by default)
- Gold issued/returned/wastage tracking
- Work status tracking
- Inventory
- Manual 22K gold and silver rates
- Customer list
- Payments and balances
- Reports
- Contact Us / phone / WhatsApp
- Logo and watermark
- Responsive animations

## Run

```bash
npm install
npm run dev
```

## Build for hosting

```bash
npm run build
```

Vite outputs the production site to `dist/`.

## Important
This version stores management data in the browser's localStorage for testing. Before using it for real customer, payment, or gold records, connect a secure database/authentication layer and configure backups.
